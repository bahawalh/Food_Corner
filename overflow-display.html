Overflow

overflow: visible;

This text is intentionally longer than the box height. With overflow visible, content can extend outside the box. This demonstrates the default visible behavior.

overflow: hidden;

This text is intentionally longer than the box height. With overflow hidden, the extra content is clipped and cannot be seen outside the box.

overflow: scroll;

This text is intentionally longer than the box height. With overflow scroll, scrollbars are available so the user can access content that does not fit inside the fixed-height box.
